# João Emanuel — Portfólio

Portfólio pessoal estático em português, com projetos em backend, desenvolvimento web, redes e modelagem de software.

## Abrir

Abra `index.html` no navegador ou sirva a pasta com um servidor estático:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Estrutura

- `index.html` — conteúdo, semântica e metadados.
- `styles.css` — identidade visual e layout responsivo.
- `script.js` — menu móvel acessível.
- `assets/favicon.svg` — ícone vetorial.

Os projetos incluem links para os repositórios de origem. Trabalhos em equipe e projetos em repositórios externos ao perfil pessoal estão identificados, com as contribuições descritas a partir do material disponível. O botão de e-mail abre uma nova mensagem no Gmail endereçada a `sousamarinho@discente.ufg.br`.
